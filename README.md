# Academic AI Platform (PoC)

Цей проект демонструє архітектурне рішення для автоматизації роботи з науковими статтями.

### Ключові особливості:
- FastAPI: Використання асинхронних ендпоінтів для високої продуктивності.
- Background Tasks: Генерація PDF-звітів та розсилка Email (імітація WeasyPrint/Resend) винесені у фонові процеси для миттєвої відповіді користувачу.
- AI Integration Pattern: Структура для підключення LLM (OpenAI/Claude) та реалізація паттерну RAG для роботи з контекстом журналів.
- Pydantic: Строга валідація вхідних даних.

### Як протестувати:
1. Встановіть залежності: pip install fastapi uvicorn pydantic
2. Запустіть сервер: uvicorn main:app --reload
3. Відкрийте документацію Swagger UI: http://127.0.0.1:8000/docs
